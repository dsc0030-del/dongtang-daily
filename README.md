# 東唐建設｜工務巡查日報（個人工具）

工務經理每日巡查工地用的手機 APP。與「工地自主檢查系統」完全獨立，資料只存在自己手機，不上傳任何伺服器。

## 功能
- **今日巡查**：日期＋工地下拉選單，選好即開啟（或建立）當日日報，自動儲存
- **基本資料**：天氣、氣溫、巡查時間、出工人數、主要施工項目
- **巡檢缺失紀錄**：位置、工項、說明、嚴重度、責任廠商、改善期限、狀態、缺失照片／改善後照片；可一鍵「帶入前次未改善缺失」持續追蹤
- **勞工安全衛生檢查**：10 大類 42 項，符合／不符合／不適用，不符合可填說明並拍照；可「本類其餘全部符合」
- **現場照片**：拍照或相簿多選，自動壓縮並加註「工地＋時間」浮水印（設定可關）
- **電子簽名**：手指簽名，簽名後日報鎖定；可「套用上次簽名」；需修改時解除簽名
- **匯出日報**：A4 PDF（下載／分享到 LINE、Email），或列印；含電子簽名欄與空白「主管核閱」欄可親簽
- **歷史日報**：依月份列出、可篩選工地
- **備份**：設定頁匯出／匯入 JSON（換手機用）

## 檔案
| 檔案 | 用途 |
|---|---|
| index.html | 整個 APP（單一檔案） |
| sw.js | 離線快取（工地沒網路也能用） |
| manifest.webmanifest、icon-*.png、logo.png | 加到主畫面的圖示與品牌 |

## 放到手機上使用
手機要能「加到主畫面」並離線使用，需要放在 **https 網址**。最簡單：

1. GitHub 新建一個 repo（例如 `dongtang-daily`），把本資料夾的檔案全部上傳
2. repo → Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save
3. 約 1 分鐘後用手機開 `https://<帳號>.github.io/dongtang-daily/`
4. iPhone：Safari 分享 →「加入主畫面」；Android：Chrome 選單 →「安裝應用程式」

> 第一次開啟需連網（載入 PDF 元件），之後工地沒訊號也能記錄；匯出 PDF 建議有網路時再做第一次測試。

## 注意
- 資料存在手機瀏覽器內，**清除 Safari／Chrome 網站資料會一併刪除**，請定期「匯出備份」
- 改版後若手機沒更新，把 `sw.js` 第 2 行版本號 +1
